Загрузка реестра позиций

  1. Откройте реестр позиций RTS под своей учётной записью.
  2. В DevTools → Network найдите JSON-ответ списка позиций (объект с полем page).
  3. Сохраните ответ в файл или скопируйте в поле ниже.

В подбор попадают только позиции со статусом Published (остальные импортируются выключенными, если снять фильтр). Числовые диапазоны из RTS могут не совпасть дословно с формулировками в извещении ЕИС.
